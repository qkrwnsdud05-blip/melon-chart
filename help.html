갤럭시 (안드로이드)

  1. 크롬 또는 삼성 인터넷으로 이 앱 주소를 엽니다.
  2. 크롬: 오른쪽 위 ⋮ (점 3개)를 누릅니다.
    삼성 인터넷: 아래쪽 ≡ (줄 3개)를 누릅니다.
  3. 홈 화면에 추가 또는 앱 설치를 누릅니다.
  4. 추가 (또는 설치)를 누릅니다.
  5. 바탕화면에 검은색 USB 아이콘이 생기면 끝!

화면 아래에 ‘앱 설치’ 안내가 저절로 뜨면 그걸 눌러도 돼요.

아이폰

  1. 꼭 사파리(Safari)로 이 앱 주소를 엽니다.
  2. 화면 아래 가운데 공유 버튼 (네모에 위쪽 화살표 ⬆)을 누릅니다.
    버튼이 안 보이면 화면을 살짝 위로 올려 보세요.
  3. 메뉴를 위로 올려서 홈 화면에 추가를 누릅니다.
  4. 오른쪽 위 추가를 누릅니다.
  5. 바탕화면에 검은색 USB 아이콘이 생기면 끝!

처음 열 때 한 번만

  1. 바탕화면의 엄마 노래 USB 아이콘을 누릅니다.
  2. 구글 계정으로 로그인을 누르고, 엄마 구글 계정을 고릅니다.
  3. 그다음부터는 로그인 없이 바로 열려요.
